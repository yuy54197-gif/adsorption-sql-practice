# adsorption-sql-practice

环境吸附实验数据的 **SQL / pandas 练习仓库**。

用一份真实的吸附实验数据（生物炭、层状双金属去除水中氮磷），练习数据分析与数据工程的完整链路：
**读数据 → 数据体检 → 清洗 → 入库 → SQL 查询 → 统计分析**。

---

## 数据说明

`adsorption_data.csv` 是模拟的吸附实验数据，共 **61 条记录**，字段结构参考环境吸附领域论文的常见变量。

| 字段 | 含义 | 说明 |
|---|---|---|
| 记录编号 | 实验编号 | 主键 |
| 材料类型 | 吸附材料 | 7 种（原始芦苇生物炭、Fe改性生物炭、Co/Fe-LDH@BC 等） |
| 目标污染物 | 去除对象 | 4 种（硝氮、氨氮、总磷、六价铬） |
| Fe负载量_pct | 铁负载量 | 关键自变量，0–20 |
| 热解温度_C | 制备温度 | 300–700 |
| 初始质量浓度_mgL | 初始浓度 | 10–100 |
| pH | 溶液 pH | 3.2–10.8，**含 5 条缺失** |
| 投加量_gL | 材料投加量 | 0.5–4.0 |
| 吸附时间_h | 接触时间 | 0.5–24 |
| 吸附容量_mgg | 吸附容量 | 目标变量，**含 3 条缺失** |

**数据中刻意保留了真实数据的典型问题**，用于练习数据清洗：
- 缺失值：pH 缺 5 条、吸附容量缺 3 条
- 越界值：Fe 负载量出现 5 条负值（物理上不成立）

## 数据库结构（三张表）

| 表名 | 行数 | 说明 |
|---|---|---|
| `adsorption_raw` | 61 | **原始数据，一条不改**（数据仓库原则：保留原始） |
| `adsorption_clean` | 61 | 清洗版：Fe 负值截断为 0，新增 `pH是否缺失` 标记列 |
| `adsorption_model` | 58 | 建模用：剔除目标变量缺失的 3 条 |

> 清洗采用**非破坏性**策略（截断 + 标记），而不是直接 `dropna()` 删除行。

## 已完成的查询示例

```sql
-- 1. 每种材料的平均吸附容量（对应 pandas 的 groupby + mean）
SELECT 材料类型,
       COUNT(*)                   AS 记录数,
       ROUND(AVG(吸附容量_mgg), 2) AS 平均吸附容量
FROM   adsorption_model
GROUP  BY 材料类型
ORDER  BY 平均吸附容量 DESC;

-- 2. 材料 × 污染物 双维度分组
SELECT 目标污染物, 材料类型,
       COUNT(*) AS 记录数, ROUND(AVG(吸附容量_mgg), 2) AS 平均吸附容量
FROM   adsorption_model
GROUP  BY 目标污染物, 材料类型
ORDER  BY 目标污染物, 平均吸附容量 DESC;

-- 3. 三张表的行数核对
SELECT 'adsorption_raw' AS 表名, COUNT(*) AS 条数 FROM adsorption_raw
UNION ALL SELECT 'adsorption_clean', COUNT(*) FROM adsorption_clean
UNION ALL SELECT 'adsorption_model', COUNT(*) FROM adsorption_model;
```

## 已发现的数据问题（分析笔记）

**1. 混杂变量导致错误结论（辛普森悖论）**

按材料类型直接平均吸附容量，会得出"原始芦苇生物炭最好、改性材料反而更差"的结论。
但交叉表显示：**没有任何一种材料在 4 种污染物上都被测过**，而不同污染物的吸附容量天然差异很大（六价铬均值 65.3 > 总磷 48.5 > 氨氮 46.8 > 硝氮 44.9）。

→ **必须先固定污染物类型，再比较材料**，否则结论失真。

**2. Fe 负载量才是主导因素**

按 Fe 负载量分箱后，平均吸附容量单调递增：

| Fe 负载量区间 | 记录数 | 平均吸附容量 |
|---|---|---|
| 0–1 | 17 | 34.71 |
| 1–5 | 16 | 39.51 |
| 5–10 | 4 | 42.52 |
| 10+ | 21 | **71.35** |

Fe 负载量与吸附容量的相关系数 **r = 0.866**。
说明"材料名称"只是 Fe 负载量的一个包装，真正起作用的是负载量本身。

**3. 数据本身的问题**

`Fe负载量_pct` 出现 5 条负值（最小 -0.18），物理上不成立，已截断为 0。
